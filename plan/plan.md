## 0. Позиционирование работы (одна фраза)

Классическая SIR-модель вынуждена объяснять спад волны только истощением восприимчивых
(иммунной прослойкой) и потому либо переоценивает долю переболевших, либо не воспроизводит
наблюдаемую асимметрию волны (быстрый подъём — медленный спад). Дробная производная Капуто
порядка α < 1 вносит в модель эффект памяти, что позволяет описывать асимметрию волны и
длинный спад без искусственного занижения репродуктивного числа. **Порядок α выступает
дополнительным, физически интерпретируемым параметром идентификации.**

## 2. Содержание по разделам

### 1. Введение (0.6 стр.)
- Волна заболеваемости как объект идентификации: подъём, пик, спад; несимметричность.
- Почему классические компартментные модели дают смещённые оценки при описании одной волны.
- Гипотеза: нелокальность (память) процесса — естественное объяснение асимметрии.
- Цель: сравнить точность и устойчивость оценок параметров волны классической (целый
  порядок) и дробной моделью на открытых данных нескольких городов.
- Новизна: единый протокол идентификации (α, β, γ) для 7 территорий 4 стран; α как
  количественная мера «памяти» волны; проверка прогностической ценности.
- Обзор: дробные модели в эпидемиологии (Arafa, Khan, Area; Caputo–Fabrizio; Atangana–Baleanu).

### 2. Дробные производные Капуто и их физический смысл (0.8 стр.)
- Определение дробного интеграла Римана–Лиувилля и производной Капуто (формула с ядром
  (t−s)^(−α)/Γ(1−α)).
- Почему Капуто, а не Римана–Лиувилля: у Капуто D^α C = const при постоянных начальных
  условиях, что совместимо с физической размерностью и постановкой начальных задач.
- Предельные случаи: α = 1 → обычная производная; α → 0 → накопление/память.
- Ядро степенного вида — убывающая память; связь с функцией Миттаг–Леффлера
  E_α(z) = Σ z^k/Γ(αk+1) как «дробным аналогом экспоненты».
- Физический смысл α в эпидемиологии: α < 1 — субдиффузия/замедленная перестройка
  поведения и контактов; неэкспоненциальный распад инфицированных; α — мера инерции
  (памяти) популяции. Обсудить, что α не является биологическим параметром вируса.
- Формула связи начальной скорости роста и параметров: λ^α = β − γ (линеаризация у нуля).

### 3. Данные и объекты исследования (0.5 стр.)
- **Таблица 1:** территория, страна, тип единицы, население, источник, период, число наблюдений.
- Набор территорий (7): Москва; Псковская обл.; Калининградская обл.; Новгородская обл.;
  Нью-Йорк (5 боро); Милан (провинция); Дели.
- Все источники — открытые, машиночитаемые, с фиксированным URL и контрольной суммой
  SHA-256 (приводится в приложении к коду); скрипт загрузки прилагается.
- Правило выбора окна волны: фазы роста и спада наблюдаются полностью, суточная
  заболеваемость на границах окна мала по сравнению с пиком.
- Оговорка: для России доступен только период 26.03–17.10.2020, поэтому берётся первая
  волна; для Дели первая полностью наблюдаемая волна — осенняя 2020 г. (данные начинаются
  с 12.09.2020) — берётся волна «дельта» (весна 2021).
- Честная оговорка о неоднородности: регистрация случаев зависит от тестирования;
  вводится коэффициент регистрации ρ.

### 4. Классическая модель и оценка параметров (0.8 стр.)
- SIR (уравнения (1)–(3)) с начальными условиями.
- Наблюдаемая величина: накопленное число подтверждённых случаев C_obs(t) = ρ·(N − S(t)),
  ежедневный прирост как основная характеристика волны.
- Оценка: метод наименьших квадратов по накопленной кривой, лог-параметризация,
  многократный запуск из разных начальных приближений; доверительные интервалы по
  матрице Якоби.
- Метрики: RMSE, R², AIC; отдельно — прогноз на 14 дней вперёд при обучении на
  «подъём + пик».
- **Рис. 1:** данные и подгонка классической SIR для основной территории (Москва);
  график остатков.
- Показать проблему: классическая модель требует нереалистичной доли переболевших или
  даёт систематическую ошибку на спаде.

### 5. Дробная модель и идентификация параметров (0.9 стр.)
- Caputo-SIR (уравнения (4)–(6)).
- Численная схема L1 для дробной производной (дискретизация Капуто, весовые
  коэффициенты b_j = (j+1)^{1−α} − j^{1−α}), явная схема, оценка порядка точности O(Δt^{2−α}).
- Стоимость O(n²) на историю; приёмы ускорения.
- Целевая функция, ограничения на параметры, алгоритм оптимизации (trust-region
  reflective least squares + multi-start).
- Идентифицируемость: коллинеарность β и ρ; параметризация через κ = ρN; доверительные
  интервалы; профиль по α.
- **Рис. 2:** чувствительность решения к α (семейство кривых при фиксированных β, γ).

### 6. Результаты и сравнение (1.2 стр.)
- **Таблица 2:** оценки (β, γ, R₀, α, κ, N, RMSE, R², AIC) по всем 7 территориям для
  классической и дробной моделей.
- **Таблица 3:** устойчивость — 14-дневный прогноз (MAPE) для целой и дробной моделей;
  разброс α по волнам Нью-Йорка (весна 2020, зима 2020/21, дельта, омикрон).
- **Рис. 3:** наложение подгонок целой и дробной моделей на данные (Москва) + остатки.
- **Рис. 4:** сводная диаграмма: α по территориям с 95 % доверительными интервалами.
- Ключевые результаты (формулировки-заготовки, уточняются по расчёту):
  1. α статистически значимо меньше 1 для всех рассмотренных волн.
  2. Дробная модель снижает RMSE и AIC относительно классической SIR при большем числе
     параметров ровно на один.
  3. Оценки α группируются в диапазоне, характерном для «замедленных» волн; для волны
     омикрон α ближе к 1.
  4. Прогноз спада дробной моделью точнее.

### 7. Обсуждение и выводы (0.6 стр.)
- Интерпретация α как меры памяти/инерции; почему α не равен «биологическому» параметру.
- Ограничения: качество регистрации, отсутствие данных по серопревалентности, выбор окна.
- Практическая ценность: α как дополнительный дескриптор волны для сравнения территорий и
  периодов; возможность строить краткосрочный прогноз спада.
- Направления развития: дробные SEIR/SEIQR, переменный порядок α(t), байесовская оценка.
