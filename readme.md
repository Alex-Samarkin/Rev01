## Модель и метод

Классическая SIR-модель и её дробный аналог с производной Капуто порядка α ∈ (0, 1]:

```
D^α S = −β S I / A,   D^α I = β S I / A − γ I,   C(t) = A − S(t)
```

Параметризация — через эпидемиологически интерпретируемые величины (λ — начальная скорость
роста, τ — длительность инфекционного периода, A — эффективная численность):

```
γ = τ^(−α),   β = γ + λ^α,   R₀ = 1 + (λτ)^α
```

Численное решение — явная схема L1 для производной Капуто (Δt = 0,1 сут). Схема
верифицирована сопоставлением с функцией Миттаг-Леффлера: при α = 1/2, λ = 1, t = 1
точное значение E_{1/2}(−1) = e·erfc(1) = 0,4275835762, схема даёт 0,4274983 (n = 1000).

## Главный результат

Дробная модель значимо улучшает описание волны для **5 территорий из 7** (ΔAIC от 24 до 469,
снижение RMSE до 78 %); для Новгородской области и Дели α статистически неотличим от единицы.
Классическая SIR систематически занижает R₀ в 1,15–1,30 раза.

| Территория | α (95 % ДИ) | R₀: классическая → дробная | ΔAIC |
|---|---:|---|---:|
| Калининградская область | 0,387 (0,331–0,442) | 1,419 → 1,839 | +135,5 |
| Москва | 0,413 (0,389–0,438) | 1,565 → 2,001 | +291,3 |
| Нью-Йорк | 0,416 (0,403–0,428) | 1,663 → 2,122 | +468,7 |
| Милан | 0,530 (0,501–0,560) | 1,522 → 1,903 | +140,9 |
| Псковская область | 0,618 (0,522–0,713) | 1,506 → 1,718 | +23,9 |
| Новгородская область | 0,839 (0,732–0,947) | 1,423 → 1,506 | −0,0 |
| Дели | 0,990 (0,975–1,000) | 2,458 → 2,444 | −0,4 |

Оценки устойчивы к длительности инфекционного периода: при τ от 5 до 10 суток α меняется
не более чем на 0,03. Обе реализации (Python и Julia) совпадают с относительным расхождением
~10⁻¹².

## Вторая линия: дробная SEIR-модель по волнам Москвы

Параллельно в проекте развивается постановка с SEIR-моделью (блокноты
`02_moscow_fractional_seir_*.jl`, статья — `03_article.md`). Она независимо воспроизведена
на Python:

* `code/python/fractional_seir.py` — решатель на схеме L1 и две схемы идентификации:
  * `fit_seir_notebook` — воспроизведение постановки блокнота: σ и γ фиксированы по
    литературе (инкубация 5,5 сут, заразность 10 сут), E₀ выводится из данных,
    оцениваются β, q и α;
  * `fit_seir` — расширенная постановка (оцениваются σ, γ, амплитуда или E₀)
    с двумя наборами границ — широким и физиологичным;
* `code/python/run_seir.py` — драйвер, работает многопроцессно
  (`--method notebook|pipeline`).

**Проверка сходимости:** RMSE дробной модели на волне 1 — 541,5 (в отчёте блокнота ≈546),
классической — 626,1 (≈566), то есть реализация воспроизводит результат блокнота.
Результаты: `results/seir_notebook.csv`, `results/seir_identification.csv`.

**Ключевой вывод:** эффект дробного порядка зависит и от волны, и от наблюдаемой величины —
для волны 1 снижение RMSE составляет 13,5 % (суточная кривая) и 43,0 % (накопленная),
для волны «дельта» ≈6,5 %, а для осенней волны 2021 г. α статистически неотличим от единицы.

## Ограничения среды, зафиксированные при работе

- Прямой сетевой доступ из PowerShell блокирован на уровне TLS
  (`SEC_E_NO_CREDENTIALS`); загрузка выполнена через Node.js (свой TLS-стек).
  В `code/fetch_data.js` это учтено.
- Установка пакетов Julia и прекомпиляция в этой среде падают с
  `IOError: pipe_open: bad file descriptor (EBADF)` — запрещены пайпы. Поэтому модуль
  `code/julia/fractional_sir.jl` написан **только на стандартной библиотеке** и запускается
  с флагом `--compiled-modules=no`. Pluto-блокнот `code/julia/wave_identification_pluto.jl`
  предназначен для обычной машины пользователя; здесь проверены его синтаксис и всё
  вычислительное ядро.
